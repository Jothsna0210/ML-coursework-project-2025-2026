# Machine Learning: Optimization Algorithms & Predictive Modeling

This repository contains MATLAB implementations and analytical reports developed as part of coursework.

## Repository Structure

* optimization-algorithms.pdf
  * Mathematical derivation and manual verification of critical points via Hessian eigenvalue classification.
  * Custom, from-scratch implementations of **Standard Gradient Descent**, **Gradient Descent with Momentum**, and **Adagrad** (no built-in optimization toolboxes).
  * 3D loss surface and vector trajectory visualizations (`surf`, `quiver3`).
* energy-predictive-modeling.pdf
  * End-to-end data preprocessing on the 19,700+ sample UCI Appliances Energy dataset.
  * Feature engineering, temporal parsing, IQR outlier capping, and multicollinearity filtering.
  * Multiple Linear Regression derived and implemented via the closed-form **Normal Equation**.
  * Model evaluation using RMSE, MAE, R^2, and residual distribution diagnostics.

## Tools & Technologies
* **Language/Platform:** MATLAB / MATLAB Live Scripts
* **Core Concepts:** First-Order Optimization, Multivariable Calculus, Exploratory Data Analysis, Linear Regression, Residual Diagnostics
